# Propiedad Chile - Plataforma Inmobiliaria 🏢🇨🇱

Este proyecto es una Landing Page interactiva y responsiva desarrollada con **React**, **Vite** y **Bootstrap 5** para la asignatura *Desarrollo Web Avanzado* de **INACAP - Sede Renca** (Evaluación de Proyecto Final - Proyecto N°13).

## 🚀 Características del Proyecto
* **Navbar Responsivo**: Incluye menú hamburguesa para dispositivos móviles y una barra de búsqueda integrada que filtra propiedades en tiempo real.
* **Filtros Avanzados**: Selectores dinámicos para buscar inmuebles por tipo (Casa/Departamento) y rangos de precio máximo en UF.
* **Grid System Adaptable**: Diseño completamente responsivo optimizado para resoluciones de 360px (mobile), 768px (tablet) y 1920px (desktop).
* **Modal de Detalles**: Ventana modal interactiva que carga dinámicamente la descripción y una galería de imágenes de la propiedad seleccionada.
* **Acordeón de Financiamiento**: Módulo colapsable exclusivo que detalla las opciones de crédito hipotecario, subsidios (MINVU) y pago al contado en Chile.
* **Formulario de Contacto Validado**: Formulario controlado mediante estados de React con validación de campos obligatorios y formato de correo electrónico, entregando feedback visual inmediato mediante alertas de Bootstrap.

## 🛠️ Tecnologías Requeridas & Dependencias
* **React 18+** (JSX)
* **Vite** (Bundler de alta velocidad)
* **Bootstrap 5+** (Estilos y componentes interactivos)
* **Bootstrap Icons** (Librería de fuentes e íconos)
